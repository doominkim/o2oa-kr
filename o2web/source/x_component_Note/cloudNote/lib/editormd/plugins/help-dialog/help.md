##### 키보드 단축키 (Keyboard shortcuts)

> If Editor.md code editor is on focus, you can use keyboard shortcuts.
    
| Keyboard shortcuts (키보드 단축키)              |   설명                            | Description                                        |
| :---------------------------------------------- |:--------------------------------- | :------------------------------------------------- |
| F9                                              | 실시간 미리보기 전환              | Switch watch/unwatch                               |
| F10                                             | 전체 화면 HTML 미리보기(Shift + ESC로 종료) | Full preview HTML (Press Shift + ESC exit)         |
| F11                                             | 전체 화면 전환                    | Switch fullscreen (Press ESC exit)                 |
| Ctrl + 1~6 / Command + 1~6                      | 제목 1~6 삽입                     | Insert heading 1~6                                 |
| Ctrl + A / Command + A                          | 모두 선택                         | Select all                                         |
| Ctrl + B / Command + B                          | 굵게 삽입                         | Insert bold                                        |
| Ctrl + D / Command + D                          | 날짜·시간 삽입                    | Insert datetime                                    |
| Ctrl + E / Command + E                          | Emoji 기호 삽입                   | Insert &#58;emoji&#58;                             |
| Ctrl + F / Command + F                          | 찾기/검색                         | Start searching                                    |
| Ctrl + G / Command + G                          | 다음 검색 결과로 이동             | Find next search results                           |
| Ctrl + H / Command + H                          | 가로줄 삽입                       | Insert horizontal rule                             |
| Ctrl + I / Command + I                          | 기울임 삽입                       | Insert italic                                      |
| Ctrl + K / Command + K                          | 인라인 코드 삽입                  | Insert inline code                                 |
| Ctrl + L / Command + L                          | 링크 삽입                         | Insert link                                        |
| Ctrl + U / Command + U                          | 순서 없는 목록 삽입               | Insert unordered list                              |
| Ctrl + Q                                        | 코드 접기 전환                    | Switch code fold                                   |
| Ctrl + Z / Command + Z                          | 실행 취소                         | Undo                                               |
| Ctrl + Y / Command + Y                          | 다시 실행                         | Redo                                               |
| Ctrl + Shift + A                                | @링크 삽입                        | Insert &#64;link                                   |
| Ctrl + Shift + C                                | 인라인 코드 삽입                  | Insert inline code                                 |
| Ctrl + Shift + E                                | Emoji 삽입 대화 상자 열기         | Open emoji dialog                                  |
| Ctrl + Shift + F / Command + Option + F         | 바꾸기                            | Replace                                            |
| Ctrl + Shift + G / Shift + Command + G          | 이전 검색 결과로 이동             | Find previous search results                       |
| Ctrl + Shift + H                                | HTML 엔티티 문자 대화 상자 열기   | Open HTML Entities dialog                          |
| Ctrl + Shift + I                                | 이미지 삽입                       | Insert image &#33;[]&#40;&#41;                     |
| Ctrl + Shift + K                                | TeX(KaTeX) 수식 기호 삽입         | Insert TeX(KaTeX) symbol &#36;&#36;TeX&#36;&#36;   |
| Ctrl + Shift + L                                | 링크 삽입 대화 상자 열기          | Open link dialog                                   |
| Ctrl + Shift + O                                | 순서 있는 목록 삽입               | Insert ordered list                                |
| Ctrl + Shift + P                                | PRE 삽입 대화 상자 열기           | Open Preformatted text dialog                      |
| Ctrl + Shift + Q                                | 인용 삽입                         | Insert blockquotes                                 |
| Ctrl + Shift + R / Shift + Command + Option + F | 모두 바꾸기                       | Replace all                                        |
| Ctrl + Shift + S                                | 취소선 삽입                       | Insert strikethrough                               |
| Ctrl + Shift + T                                | 표 삽입 대화 상자 열기            | Open table dialog                                  |
| Ctrl + Shift + U                                | 선택한 글자를 대문자로 변환       | Selection text convert to uppercase                |
| Shift + Alt + C                                 | ```코드 삽입                      | Insert code blocks (```)                           |
| Shift + Alt + H                                 | 도움말 대화 상자 열기             | Open help dialog                                   |
| Shift + Alt + L                                 | 선택한 텍스트를 소문자로 변환     | Selection text convert to lowercase                |
| Shift + Alt + P                                 | 페이지 나누기 삽입                | Insert page break                                  |
| Alt + L                                         | 선택한 텍스트를 소문자로 변환     | Selection text convert to lowercase                |
| Shift + Alt + U                                 | 선택한 각 단어의 첫 글자를 대문자로 변환 | Selection words first letter convert to Uppercase  |
| Ctrl + Shift + Alt + C                          | 코드 블록 삽입 대화 상자 열기     | Open code blocks dialog                            |
| Ctrl + Shift + Alt + I                          | 이미지 삽입 대화 상자 열기        | Open image dialog                                  |
| Ctrl + Shift + Alt + U                          | 선택한 텍스트의 첫 글자를 대문자로 변환 | Selection text first letter convert to uppercase   |
| Ctrl + Alt + G                                  | 지정한 줄로 이동                  | Goto line                                          |
