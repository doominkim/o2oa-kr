쿼리문 설정

문법

1. JPQL 문법

쿼리문은 JPA JPQL 문을 지원합니다. 예를 들어 다음 문은 시스템 테이블 Task에서 결재 대기 항목을 가져옵니다.

SELECT o FROM Task o WHERE o.person = :person

JPQL 공식 사이트: https://www.objectdb.com/java/jpa/query/jpql/structure
중국어 소개: https://www.codercto.com/a/4338.html

2. 네이티브 SQL 문법

v8.0 이상 버전에서는 쿼리문이 네이티브 SQL 문법을 지원합니다. 예를 들어 다음 문은 시스템 테이블 Task에서 결재 대기 항목을 가져옵니다.

SELECT * FROM PP_C_TASK WHERE xperson = :person

w3schools 사이트: https://www.w3schools.com/sql/default.asp
중국어 사이트: https://www.runoob.com/sql/sql-tutorial.html

where 절 매개변수 전달

1. 콜론으로 동적 매개변수 전달

쿼리문의 where 절 값은 json으로 전달할 수 있습니다. 예:
쿼리문 설계:

select o from tableName o where o.name=:n

쿼리문 서비스를 호출할 때 json 전달:

{
  "parameter": {
    "n" : "zhangsan"
  }
}

최종적으로 시스템이 백엔드에서 이 설계를 바탕으로 다음 문을 조합합니다.

select o from tableName o where o.name='zhangsan'

아래 그림과 같습니다.
JPQL 문의 동적 매개변수 전달은 다음 링크에서 확인할 수 있습니다: https://www.objectdb.com/java/jpa/query/parameter

2. 물음표와 숫자로 동적 매개변수 전달

V8.0에서는 물음표와 숫자 형식으로 where 절 값을 전달할 수 있으며, 콜론 동적 매개변수 전달과 비슷하게 동작합니다. 예:
쿼리문 설계:

select o from tableName o where o.name= ?1

쿼리문 서비스를 호출할 때 json 전달:

{
  "parameter": {
    "?1" : "zhangsan"
  }
}

최종적으로 시스템이 백엔드에서 이 설계를 바탕으로 다음 문을 조합합니다.

select o from tableName o where o.name='zhangsan'

아래 그림과 같습니다.

3. 기본 매개변수

시스템에는 몇 가지 기본 매개변수가 있으며, 시스템이 이 매개변수에 값을 자동으로 할당합니다.

기본 매개변수 의미 유형
person 현재 사용자 문자열
identityList 현재 사용자 소속 목록 배열
unitList 현재 사용자의 직속 조직 배열
unitAllList 현재 사용자가 속한 모든 조직 배열
groupList 현재 사용자가 속한 그룹 배열
roleList 현재 사용자가 가진 역할 배열

다음과 같은 문이 있다고 가정합니다.

select o from Task o where o.person = :person

매개변수 :person은 현재 사용자입니다.
v8.0 이전에는 외부에서 {person: ""} 매개변수를 전달하면 됩니다.
v8.0 이후에는 시스템이 이 기본 매개변수를 자동으로 해석하므로 따로 전달할 필요가 없습니다.
현재 사용자가 홍길동@hong@P이면 시스템이 해석한 뒤 다음과 같이 자동 조합합니다. 

select o from Task o where o.person = "홍길동@hong@P"

필터 조건

1. JPQL 필터 조건

쿼리문의 where 절 조건은 filterList로도 전달할 수 있습니다. 다음과 같은 쿼리문이 있다고 가정합니다.

SELECT o FROM Task o

쿼리문을 호출할 때 filterList 전달

{
    "filterList": [
        {
    	    "path":"o.title",
            "comparison":"like",
            "value":"o_title",
            "formatType":"textValue"
        }
    ],
    "parameter": {
        "o_title": "%회의%"
    }
}

최종적으로 시스템이 백엔드에서 이 설계를 바탕으로 다음 문을 조합합니다.

select o from Task o where o.title like '%회의%'

아래 그림과 같습니다.

2. 네이티브 SQL 필터 조건

쿼리문의 where 절 조건은 filterList로도 전달할 수 있습니다. 다음과 같은 쿼리문이 있다고 가정합니다.

SELECT * FROM PP_C_TASK

쿼리문을 호출할 때 filterList 전달

{
    "filterList": [
        {
    	    "path":"xtitle",
            "comparison":"like",
            "value":"xtitle",
            "formatType":"textValue"
        }
    ],
    "parameter": {
        "xtitle": "%회의%"
    }
}

최종적으로 시스템이 백엔드에서 이 설계를 바탕으로 다음 문을 조합합니다.

SELECT * FROM PP_C_TASK where xtitle like '%회의%'

아래 그림과 같습니다.

3. 필터 조건 매개변수 설명

{
    "filterList": [
        {
    	    "path":"o.title", //sql에서는 xtitle 사용
            "comparison":"like",
            "value":"o_title", //sql에서는 xtitle 사용
            "formatType":"textValue"
        }
    ],
    "parameter": {
        "o_title": "%회의%" //sql에서는 xtitle 사용
    }
}

path

  • String
  • 필터링할 data 데이터의 경로
    JPQL에서는 쿼리문의 "테이블 별칭.필드명" 형식입니다(예: "o.title").
    SQL에서는 쿼리문의 "필드명" 형식입니다(예: "xtitle").

comparison

  • String
  • 비교 연산자. 사용 가능한 값:
    equals 또는 == : 같음.
    notEquals 또는 != : 같지 않음.
    greaterThan 또는 > : 보다 큼.
    greaterThanOrEqualTo 또는 => : 크거나 같음.
    lessThan 또는 < : 보다 작음.
    lessThanOrEqualTo 또는 <= : 작거나 같음.
    like : 부분 일치.
    notLike : 일치하지 않음.
    in : 지정한 여러 값 중 하나에 해당.

formatType

  • String
  • 필터링할 데이터의 데이터 유형. 사용 가능한 값:
    textValue : 텍스트.
    numberValue : 숫자.
    dateTimeValue : 날짜 시간.
    dateValue : 날짜만.
    timeValue : 시간만.
    booleanValue : 불리언 값.

value

  • String | Number | Boolean
  • 필터링할 값. formatType에 맞는 데이터 유형의 값을 제공합니다.

기타 주의사항

1. 날짜 형식 작성법

sql에서는 날짜 형식을 텍스트로 쓰면 됩니다. 예:"2019-12-31", "23:59:59", "2020-01-03 13:59:59".
jpql에서는 날짜 형식에 특별한 작성법이 있으며 형식은 다음과 같습니다.
Date - {d 'yyyy-mm-dd'} - for example: {d '2019-12-31'}
Time - {t 'hh:mm:ss'} - for example: {t '23:59:59'}
Timestamp(DateTime) - {ts 'yyyy-mm-dd hh:mm:ss'} - for example: {ts '2020-01-03 13:59:59'}
예시는 아래 그림과 같습니다.

2. like 작성법

연산자로 like를 쓰면 부분 일치 검색이며 값은 "%{value}%"입니다.
