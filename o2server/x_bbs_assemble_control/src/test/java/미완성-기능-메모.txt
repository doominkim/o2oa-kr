1. 최적화
	1) 업무 정보 권한 필터:
	   1) 현재 방식: workPerson에서 현재 사용자가 볼 수 있는 모든 업무 또는 중점 업무의 ID를 먼저 가져오고, 지정한 매개변수로 업무 또는 중점 업무 정보를 조회한 뒤 마지막으로
	   앞서 조회한 열람 권한 ID와 교집합을 구한다.
	   2) 문제: 사용자가 볼 수 있는 업무가 많으면 in 절의 매개변수 개수가 너무 많아져 조회에 문제가 생긴다.
	   3) 개선안: 필터·정렬에 필요한 열을 workPerson에 중복 저장해 workPerson에서 최종 조회·필터·페이지 처리를 하고, 페이지 처리된 ID만 구해 실제 업
	   무 또는 중점 업무 정보 테이블에서 ID로 소량만 조회한다.
	   
	권한: 책임자, 배정자, 협조자, 열람자
	제목, 분류, 등급   
	
	2) 데이터 삭제 권한 제어
	3) 데이터 수정 권한 제어
	
2. 기능 구현
    1) 업무 배정 시 처리 체인을 기록해 둔다(나중에 사용)
    2) 업무 배정 기능 디버깅
    3) 상태별 업무 조회 기능
    4) 업무 결재 대기 정보 디버깅
    5) 결재 대기 처리 기능
    
    내가 배정한 업무
    내가 책임진 업무
    내가 협조하는 업무
    내가 열람하는 업무
    
    업무 ID로 그 업무의 모든 업무 보고 목록 조회
   업무 ID로 그 업무의 모든 문의 목록 조회  
      업무 ID로 그 업무의 모든 업무 소통 목록 조회  
      
    2) 업무 보고 처리 기능
    3) 업무 보고 삭제 기능
    4) 업무 보고 조회·페이지 기능
